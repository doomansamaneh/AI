# سرفصل‌های هزینه (کدینگ حساب‌های هزینه)

> این سند فهرست کامل **سرفصل‌های هزینه** است که در بخش **هزینه** (منوی «دریافت و پرداخت») در هر ردیف هزینه از لیست انتخاب می‌شود.
> هر سرفصل یک **کد حسابداری ۵ رقمی** و یک **گروه** دارد. انتخاب سرفصل در هر ردیف هزینه اجباری است.

## ساختار کدگذاری

سه رقم اول کد، گروه هزینه را مشخص می‌کند:

| پیشوند کد | گروه هزینه |
|---|---|
| 801 | حقوق و دستمزد مستمر |
| 802 | حقوق و دستمزد غیرمستمر |
| 803 | حق بیمه سهم کارفرما |
| 804 | هزینه‌های عملیاتی |
| 805 | هزینه‌های توزیع و فروش |
| 806 | هزینه‌های اداری و تشکیلاتی |
| 807 | هزینه‌های مالی |
| 808 | هزینه استهلاک |
| 809 | سایر هزینه‌های عملیاتی |
| 810 | هزینه خرید |

در بیشتر گروه‌ها، کدی که به **99** ختم می‌شود (مثل 80499 یا 80599) سرفصل «سایر» یا «متفرقه» همان گروه است.
